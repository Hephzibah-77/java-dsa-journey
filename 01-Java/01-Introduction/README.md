# 📝 Notes

## What is Java?

Java is an object-oriented, platform-independent, high-level programming language. It was developed by Sun Microsystems. It follows the WORA (Write Once, Run Anywhere) principle.

## History of Java

Java was developed by James Gosling and his team at Sun Microsystems. It was first released in 1995. Today, Java is maintained by Oracle.
## Features of Java
1. Object-Oriented: Java follows Object-Oriented Programming.
It organizes programs using classes and objects.This makes code reusable, easy to maintain.
2. Platform-Independent: Java follows WORA (Write Once Run Anywhere) It compiles the source code into bytecode using compiler(javac) and the bytecode is used in different operating systems that contains JVM(Java Virtual Machine) .
3. Simple: Java is simple to use because it removes the complicated features of C++, making it easier to learn and maintain.
4. Secure: Java is designed with security in mind. Some reasons are: Bytecode verification, JVM provides a secure execution environment 
EX: Java is widely used in Banking.
5. Robust: Robust means strong and reliable. Java reduces crashes by providing Exception Handling, Automatic Garbage collection.
6. Portable: Java can run on different operating systems using the same code. The Java program doesn't need to be modified when moving from one platform to another.
7. Multi-Threaded: Java can perform same 
tasks at the same time. 
Ex: While downloading a file, we can still browse the internet or listen to music.
8. High Performance: Java is generally faster than interpreted languages due to its Just-In-Time Compiler.
9. Distributed: It helps building applications by connecting computers to a network.
Ex: Online-Banking
10. Dynamic: Java supports loading Classes and Methods during run time.

## Java Compilation Process:
The .java source code is compiled by the Java compiler (javac), which is part of JDK, into bytecode (.class). The JVM executes the bytecode and converts it into machine code, allowing the Java program to run.

## Bytecode VS Machine code:
Bytecode:
Bytecode is generated by the Java compiler after compiling the .java source code. It is understood and executed by the JVM. Bytecode is platform-independent.
Machine code:
Machine code is the low-level code that is directly understood and executed by the CPU. It is platform-dependent because different systems use different machine instructions.

## Platform-Independent:
The (.java) source code is compiled by java compiler(javac) to bytecode(.class). The JVM executes  bytecode and converts it into machine code which can run on any operating system that contains JVM . Java follows WORA(Write once run anywhere) that means the bytecode can be run on any OS which has JVM

## Why doesn't Java compiler directly convert .java source code into machine code?
Java uses the javac compiler to convert source code into bytecode. The bytecode can run on different operating systems through their respective JVMs. The JVM executes the bytecode and translates it into machine code, which supports Java's platform independence and WORA principle.

## Scanner
Scanner is a class in java.util package. Used to read input from variaous sources, most commonly user input from the keyboard.
- It provides methods to read different types of data such as integers, floating point numbers, strings.
Ex: import java.util.Scanner;
    Scanner sc = new Scanner (System.in);
    int age = nextInt();
1. import java.util.scanner -  Imports scanner from java.util package.
2. new scanner (System.in) - creates new scanner object used to read data from standard input.
3. sc - reference variable, used to access scanner methods.
4. nextInt() - reads the next integer entered by the user.
5. System.in - It represents the standard input stream, normally receives the input from keyboard .
