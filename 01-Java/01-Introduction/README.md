# 📝 Notes

## What is Java?

Java is an object-oriented, platform-independent, high-level programming language. It was developed by Sun Microsystems. It follows the WORA (Write Once, Run Anywhere) principle.

## History of Java

Java was developed by James Gosling and his team at Sun Microsystems. It was first released in 1995. Today, Java is maintained by Oracle.
## Features of Java
1. Object-Oriented: Java follows Object-Oriented Programming.
It organizes programs using classes and objects.This makes code reusable, easy to maintain.
2. Platform-Independent: Java follows WORA (Write Once Run Anywhere) It compiles the source code into bytecode using compiler(javac) and the bytecode is used in different operating systems that contains JVM(Java Virtual Machine) .
3. Simple: Java is simple to use because it removes the complicated features of C++, making it easier to learn and maintain.
4. Secure: Java is designed with security in mind. Some reasons are: Bytecode verification, JVM provides a secure execution environment 
EX: Java is widely used in Banking.
5. Robust: Robust means strong and reliable. Java reduces crashes by providing Exception Handling, Automatic Garbage collection.
6. Portable: Java can run on different operating systems using the same code. The Java program doesn't need to be modified when moving from one platform to another.
7. Multi-Threaded: Java can perform same 
tasks at the same time. 
Ex: While downloading a file, we can still browse the internet or listen to music.
8. High Performance: Java is generally faster than interpreted languages due to its Just-In-Time Compiler.
9. Distributed: It helps building applications by connecting computers to a network.
Ex: Online-Banking
10. Dynamic: Java supports loading Classes and Methods during run time.

## JRE 
JRE- Java Runtime Environment. It provides everything needed to run a java program. It contains JVM and Java Libraries

## JDK
JDK - Java Development Kit. JDK contains JRE
JRE contains JVM.JDK provides everything required to develop Java applications.
