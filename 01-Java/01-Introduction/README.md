## What is Java?
Java is an object-oriented, platform-independent, high-level programming language. It is developed by Sun Microsystems. It follows WORA (Write Once Run Anywhere)
## History of Java
Java was developed by James Gosling and his team at Sun Microsystems. It was released in 1995. And now it is maintained by Oracle
